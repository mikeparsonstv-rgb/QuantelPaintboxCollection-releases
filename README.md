# Quantel Paintbox Collection — releases

Two separate apps live here. Each has its own downloads and its own updates; neither updates into the other, and both can be installed side by side.

## Paintbox Collection 2 — the Paintboxes (16 October 2026)

Three Quantel Paintboxes chosen from one loading screen: **Digital Fine Art** (the DFA-7000, the 1981 prototype), the **Classic Paintbox** (DPB 7000/1, V4.06) and the **Paintbox V-Series** (V7). New logos and welcome screens, the V-series chalk in every machine, and the DFA's cursor throughout.
